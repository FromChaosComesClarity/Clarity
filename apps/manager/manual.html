1. Manifesto & Philosophy

Your Library. Manageable. Searchable. Portable.

I wanted an app that could organize and launch all my games — from Steam, GOG, Epic, Flatpak, Emulators, or whatever — in just one place.

I wanted it to be complete with all the features I’ve always wished I had in a Linux game manager: checking YouTube videos, HowLongToBeat, and ProtonDB right from inside the app, among other things.

I wanted it to be simple, beautiful and themeable.

And most importantly, I wanted it to be completely PORTABLE and BACKUPABLE.

The Local-Only Philosophy

Clarity is built with a strict Offline-First, Local-Only philosophy for your media. Once you fetch artwork, covers, logos, or download a trailer, it is saved securely into your local GameManagerConfig folder.

This means your library will never suffer from “link rot” or broken web images if a storefront changes its API. It also means you can pack up the entire folder, put it on a thumb drive, and take your flawlessly curated library to another PC entirely.

The Launch Command

The crucial feature. Inside the Edit Details screen, there is a field where you can put a command to launch any game. Anything goes — if you can run it on Linux, you can run it from here.

If you imported your games from Steam, or from GOG and Epic through Installer, the launch commands are filled in automatically, even if the game is not installed. Clicking PLAY will prompt you to install if needed.

2. The Suite at a Glance

Clarity is one AppImage with three faces. There is nothing to install and nothing extra to download — every part of the suite ships inside the single file.

The Three Faces

  • The Manager — the desktop face. Import, organize, scrape, edit and launch your library with a mouse and keyboard. This is where you are right now.
  • Couch — the fullscreen, gamepad-first face for the living room. Same library, same artwork, same playlists — zero configuration, always in sync. Launch it with the Couch button in the titlebar or run the AppImage with --couch.
  • Installer — the GOG & Epic engine. It signs in to your accounts, downloads games, configures Proton and launches them. It works silently inside the other two faces and has no window of its own: everything it used to show is in the Manager.

EmuLatte, the ROM library manager, is a separate app — but the suite detects EmuLatte.AppImage sitting in the same folder and integrates it into your app menu and sidebar.

Your ROM library stays in EmuLatte; the suite does not swallow it. You decide which games cross over by exporting them to Clarity from inside EmuLatte — only those appear here, as ordinary library entries filed under Emulation, which play, scrape and join playlists like any other game. Keep the whole collection in EmuLatte and promote just the ones you want on the shelf.

All three faces read and write the same library database. Mark a favourite on the couch and it is a favourite on the desktop. Install a game from Couch and the Manager knows immediately.

3. Quick Start

The Welcome to the System screen appears on every launch (until you tell it not to) and walks you through the whole setup in three steps — each with live buttons, so you never have to leave the screen:

  1. Import your games. Steam: paste your free API key and SteamID64, hit Fetch Steam Library. GOG & Epic: press Sign in right here — a store login window opens, you log in, and it closes itself. After that, new purchases import automatically every time you press Refresh Library. Flatpak, PICO-8 and itch.io games are picked up automatically when you open their filters.
  2. Fetch artwork & metadata. One button scrapes covers, hero art, logos, descriptions, HowLongToBeat and ProtonDB data for everything you just imported.
  3. Add to your app menu. One click registers Clarity and Couch (and EmuLatte, if detected) in GNOME, KDE or any desktop launcher, with proper icons.

Bring it back anytime: the Welcome screen lives in Menu → System. Nothing in it is exclusive — every action also exists in Connect and the Control Panel.

Your Files

On first launch the app creates a GameManagerConfig folder next to the AppImage:

  • games.db — your entire library database: games, metadata, playlists, settings
  • images/ — covers, hero art, logos, icons, screenshots
  • trailers/ — locally downloaded MP4 trailers

Installer keeps its own data (store logins, install records) in ~/.config/installer/ — per-machine on purpose, since installed games differ between computers.

4. The Manager — Importing Your Games

Open Connect (the chain-link icon in the side rail, or Control Panel → Connections). All data stays local; no cloud account is ever required to use the app.

Steam

  • Get a free API key at steamcommunity.com/dev/apikey and your SteamID64 from your profile URL.
  • Your Steam Game Details privacy must be set to Public for the API to list your games.
  • The import includes played free-to-play titles (tagged with a green FREE pill) and even Steam’s “unvetted” small releases that the API normally hides.
  • Free games and demos you never launched are invisible to Steam’s API entirely. The Manager works around it by also reading your local Steam install folders, so anything actually installed on this machine gets imported whether Steam admits to owning it or not.
  • Playtime (total and last two weeks) is captured on every sync.

GOG & Epic

  • Sign in without leaving the Manager. The Welcome screen and Connect both have GOG and Epic sign-in buttons: press one, the store’s own login page opens in a window, and it closes itself the moment you’re authenticated. You never have to open Installer for this — it’s tucked away behind Advanced now.
  • From then on, Refresh Library pulls your full owned list from both stores automatically — buy a game, hit refresh, it appears (as “not installed”, ready to install in one click).
  • DLC and soundtracks are filtered out automatically; a GOG/Epic copy of a game you also own on Steam merges into one entry with a launcher picker.

Games That Leave

Refresh Library doesn’t only add. If you refunded a GOG or Epic game, or uninstalled a Steam demo you never owned, it now disappears from your library too instead of lingering as a dead entry forever. Games you own on more than one store lose only the store you parted with — the entry itself stays, with the remaining launcher.

Nothing you curated is at risk: only genuinely un-owned store entries are removed. Custom games, emulator entries and anything you added by hand are never touched by a refresh.

Flatpak, PICO-8, itch.io

  • Flatpak: clicking the Flatpak filter scans installed apps and even generates cover art from their icons.
  • PICO-8: point the app at your PICO-8 binary (Control Panel) and your cart folder is scanned; carts get their label art as covers, plus Splore and the BBS browser.
  • itch.io: sync your owned library through the itch integration in Connect.

Emulation (EmuLatte)

ROMs are not imported by scanning. You curate them in EmuLatte and export the ones you want from inside EmuLatte; they land here as normal library entries under Emulation. Nothing crosses over on its own, so your 3,000-ROM set never floods the shelf — only the games you chose.

Anything Else

Add Custom Game (Control Panel → Library) creates an entry for any game or app. Give it a launch command — if it runs on Linux, it runs from here. Store-less entries are filed under Others automatically.

5. The Manager — The Library

The library has two views — Gallery (cover grid) and List (a sortable table) — plus a persistent icon rail on the left.

The Search Row

Both views share the same search row at the top:

  • Search — instant, searches titles as you type.
  • Category dropdown — jump to any store or filter (Steam, GOG, Epic, Flatpak, PICO-8, itch.io, Installed, Favourites, Want to Play…). Stays in sync with the rail buttons.
  • Sort dropdown — A — Z, Last Played, Favourites First, Want to Play First, Recently Added, Scraped First. Your choice is remembered across restarts. Any sort other than A—Z hides the “Recent Games” strip so the whole grid reads in your chosen order.
  • Genre dropdown — narrow the view to a real genre: ARPG, CRPG, FPS, Metroidvania, Soulslike, Shmup, Racing… (see Genres). It combines with everything else, so GOG + CRPG + Installed is one view. The ✦ button beside it turns whatever genre you are looking at into a playlist that keeps itself up to date.
  • Playlist dropdown — jump into any playlist, the Recently Imported feed, or create a new playlist on the spot.
  • Games count — live count of what you’re looking at.

The Side Rail

Icons for All Games, Favourites, Want to Play, store filters, playlists, plus Add Game, Connect, the Control Panel and Refresh Library. Filters combine: stores are OR’d, qualifiers (Installed, Favs, Want) are AND’d.

Gallery Cards

Each cover carries its information quietly: an install dot (green = installed, orange = not), store badges, a FREE pill on free-to-play games, hover flags for Favourite / Want / Playlist, and an inline Play or Install button. One click opens the gamepage.

Ken Burns hero: the gallery header slowly pans across your library’s screenshots. If you’re on older hardware, turn it off in Control Panel → Appearance.

6. The Manager — The Gamepage

The gamepage opens as a floating panel over your library — the grid stays blurred behind it, and clicking outside (or the Back button) drops you exactly where you left off, scroll position included.

What’s On It

  • Hero art with the game’s logo, store icons and the store/category logo in the corner.
  • Action row: Favourite, Want to Play, Add to Playlist (and Remove, when it’s in one), Hide (eye icon — removes the game from every view; manage hidden games in the Control Panel), Open in Steam, Uninstall, SPLORE (PICO-8), Watch Trailer, and Edit Details.
  • Manuals (book icon) — some games, RPGs especially, still expect you to read something, and the file is usually already on your disk. Press the button and Clarity shows what it found:
    • In the game’s own folder. GOG ships manuals, cluebooks and reference cards inside the game and never mentions them. Better still, its manifest names them — so Realms of Arkania offers you “Manual”, “Cluebook” and “Password reference card”, not three filenames to guess between. One press adds any of them.
    • From GOG. For GOG games it also asks the store what it has: the scanned originals, sold alongside the game. Downloading unpacks the archive and adds every document inside — often more than one.
    • Browse for a file — anywhere on disk, for a scan or a fan-made reference. You can pick several at once.
    A game can hold as many manuals as it needs. With one attached the button just opens it; with several it lets you choose. Reading happens in its own window you can drag to a second monitor and keep open while you play, and the icon turns accent-coloured for games that have something to read.
    Remove only unlinks a manual — a file of yours, or one GOG installed, is never deleted. The single exception is a manual this app downloaded itself, which it does own and does clean up.
  • Browse Local Files (folder icon) — opens the game’s install folder in your file manager. It works out where the game actually lives for Steam, GOG, Epic and even emulator entries (following the ROM path out of the launch command), and simply doesn’t appear for games that aren’t installed.
  • Add to Desktop — writes a launcher for that one game, using its own artwork as the icon. Double-click it and Clarity opens straight on that game (or launches it, if you press Play). You’re asked each time whether it should go in the app menu, on the desktop, or both.
  • DLC panel — installed GOG games list their owned DLC, with badges for what’s already on disk and a one-press Install all DLCs.
  • Save Manager — finds, backs up and restores your save games. See section 20.
  • Floating Play/Install button, always visible at the bottom right.
  • Metadata column: achievements ring (press to see the full list), release year, developer, genre, HowLongToBeat, Metacritic, ProtonDB tier, similar games (clickable links when you own them).
  • Description — the short summary plus the full Steam page write-up, and a screenshots strip with a slideshow.
  • Click the box art to see it full-size in a lightbox.

Edit Details

Opens directly on top of the gamepage (same panel, seamless). Every field is yours to change: title, store, launch command, artwork, screenshots, description, franchise, flags. Custom art you set by hand is protected from being overwritten by re-scrapes.

7. The Manager — Installs & the Download Manager

How Installing Works

  • Steam games install through the Steam client (steam://install) — Steam opens and takes over.
  • GOG & Epic games install in-process through the built-in Installer engine: pick a folder, see the download size and your free disk space up front, and watch live progress. No external window.
  • Linux or Windows build? For the GOG games that ship both, the install dialog lets you choose — native Linux, or the Windows build run through Proton. Your choice is remembered per game.
  • Cancel really cancels: the whole download process tree is stopped, not just the parent, so a cancelled install doesn’t sit there half-finished.
  • Uninstall (gamepage action row) removes the game files and its Wine prefix.
  • Games you own on more than one store keep one entry with several launchers. Installing it anywhere counts as installed, and pressing Play asks which one you meant — the copies already on disk offer Play, the others offer to install first, so you never get a silent failure.
  • Where games land: the install dialog starts at your Game Install Folder — ~/Games/Clarity unless you change it (Control Panel → Library). Change… picks a different folder for that one game without touching the default.

Windows Games & Proton

GOG and Epic games built for Windows run through Proton, a compatibility layer. Clarity finds Proton on your machine by itself — Steam’s own builds, GE-Proton, anything installed by ProtonUp-Qt — no matter what the folder is called, and picks the best one available.

If you have none, the first Windows game you launch says so and offers to install GE-Proton for you: one click, a progress bar, roughly a 400 MB one-time download that every Windows game then shares. If you already have several builds, the same dialog lets you choose which one to use.

The first Windows game takes a few minutes to appear. Before it can start, a compatibility runtime is downloaded once for the whole machine, and each game gets its own small Windows environment built the first time you play it. The Now Playing card shows what stage it’s at, with the download counting up — it isn’t stuck. Every launch after that is immediate.

The Download Manager

Start more than one install and they queue — each begins automatically when the previous one finishes. Manage the queue from:

  • The downloads icon in the titlebar (with a live count badge) — works even when nothing is downloading.
  • The progress bar that appears at the top during any download — click it to open the manager; click outside to return to it.

Inside: the active download with live percentage and a Cancel button, the waiting queue (remove anything), and a history of completed installs. Click any game’s name to jump to its gamepage.

Phone notifications: with KDE Connect (or GSConnect) paired, the “Game installed” and “Now Playing” notifications — cover art included — appear on your phone automatically. Toggle in Control Panel → Behavior.

8. The Manager — Scraping & Artwork

Scraping fills your library with covers, hero images, logos, icons, screenshots, descriptions, genres, release years, HowLongToBeat times, Metacritic scores and ProtonDB tiers. Everything downloads to your local images/ folder — no link rot, ever.

  • Auto-Fetch (Edit Details) — one game, one click, everything found.
  • Batch Fetch (Control Panel → Library, or the Welcome screen) — sweeps every game that’s missing data. After a Refresh Library, you’re offered a scrape of just the new arrivals.
  • SteamGridDB (free key at steamgriddb.com) — browse fan-made grids, heroes and logos and pick your favourite per game.
  • IGDB (free Twitch dev credentials) — richer metadata and the fallback for non-Steam games.
  • Trailers — search YouTube from inside the app and download a local MP4; it plays on the gamepage and in Couch.

Your art is safe: re-scraping never overwrites artwork you set manually.

An optional start page that greets you before the library: a 2D widget board you can drag, resize and curate. New installs start with Roulette, Throwback and Continue Playing up top, Hidden Gems and Free This Week in the middle, and double-height Gaming News and Wishlist below.

Working the Board

  • Edit Layout — drag widgets anywhere, resize from the corner grip, remove with ×.
  • + Add Widget — every toggle applies instantly; no save button.
  • Reset — back to the default arrangement.
  • The house and book icons in the titlebar switch between Home and the library at any time.

The Widget Shelf

Online (strictly opt-in — zero network calls until you enable them): Wishlist & Deals (IsThereAnyDeal — track un-owned games and price cuts), Free This Week (Epic), Gaming News (your own RSS feeds), Your Games — What’s New (Steam patch notes for games you play), Proton Watch (games that climbed to Gold/Platinum).

10. Genres, Playlists, Hidden Games & Free-to-Play

Genres

Stores tell you where a game came from; genres tell you what it is. Clarity sorts your library into real genres — not “Action, Adventure, Indie” but ARPG, CRPG, FPS, Metroidvania, Soulslike, Shmup, Survival Horror, Point & Click and forty more.

  • Detect Genres (Control Panel → Tools) reads the tags players voted on for each game, which is the only source that can tell a Diablo-like from a Baldur’s Gate-like. Games your stores don’t know are looked up on IGDB instead. The card shows how much of your library is sorted.
  • It works through your games about one a second, so a large library takes a few minutes. You can close the window and keep playing — progress carries on in the corner toast — and stopping it keeps everything already sorted.
  • Each game gets one main genre (shown on its gamepage) plus any others that genuinely apply, so a game can be both an FPS and Horror and turn up under each.
  • Disagree with one? Set it yourself in the game’s edit panel under Filter Genre. Anything you pick by hand is pinned — no future scan will ever overwrite it.
  • Search knows genres too: typing crpg or metroidvania finds the games.

Games with no genre: PICO-8 cartridges, Flatpak apps and other titles that no store has ever listed have nothing to look up. They gather under No Genre Yet in the dropdown, where you can give them one by hand.

Playlists

  • Create from the rail, the search-row dropdown, or any game’s + Playlist button — that picker has a “+ New playlist…” box built in, so you can invent a playlist and drop the game into it in one go, even if you had none to begin with. Order is yours; games can live in many playlists.
  • Playlists that fill themselves. When you create one, pick a genre under Fill it automatically and the playlist maintains its own membership — it tells you how many games it collects before you commit, and every future game that fits simply appears in it. These are marked ✦; the games are decided by the rule, so there is no hand-editing to do.
  • Recently Imported is an automatic feed of your newest arrivals (size configurable in Behavior; newest always on top).
  • Playlists appear in Couch as first-class categories, marked with ≡. Changes sync both ways instantly.

Hidden Games

Hide anything via the Manager gamepage’s eye button — it vanishes from every view in both faces, instantly. Unhide from Control Panel → Behavior → Hidden Games. Hiding and unhiding are the Manager’s job: Couch can neither hide a game nor bring one back, because a couch face that could hide a game without being able to recover it is a one-way door. (Older builds let Couch’s menu), each game individually.

Free-to-Play

Steam free-to-play titles you’ve played are imported and tagged with a green FREE pill (gallery, list and gamepage). Click any pill — or use Control Panel → Behavior — to show or hide them all, or hide just that one game.

11. The Manager — Control Panel

The wrench icon opens the Control Panel — it lands on a title splash showing which version you are running; pick a section on the left or just start typing to search every setting.

  • Appearance — Theme Selection (93 themes in 10 families, from Catppuccin to Game Boy to a shelf of retro operating systems), Interface Font (Poppins, Sora, Inter, Fraunces, Chicago or PxPlus IBM VGA8 — all bundled, nothing fetched from the web), UI scale (50–150%), Sharp/Round corners, Ken Burns on/off.
  • Library — Update Library (full store re-sync), Add Custom Game, batch scraping, Game Install Folder, Manage Storage and Scan for Updates (all below).
  • Behavior — Gaming History, Recently Imported size, PICO-8 / Free-to-Play visibility, Hidden Games manager, desktop & phone Notifications.
  • Connections — Steam, Installer (GOG/Epic), itch.io, SteamGridDB, IGDB, PICO-8 binary.
  • System — full Backup ZIP (library + artwork + trailers + your RetroArch save states), Add to Application Menu, Couch autostart on login, the Welcome screen.
  • Cleanup — clear orphaned images, gaming history, or the nuclear options. Read twice, click once.

Themes & the Interface Font

All 93 themes are shared by all three faces — the Manager, Couch and Installer draw from the same set, so a look you like on the desktop is the same look on the TV. The families are Originals & System, BrewBalance, Light & Minimal, Gaming Legends, Aesthetics, Linux Ricing, Sci-Fi Universes, Horror Realm, PSIII Colors and Systems — twenty faithful retro-OS palettes (MS-DOS, Commodore 64, Windows 3.1 / 95 / XP, Amiga Workbench, BeOS, NeXTSTEP, ZX Spectrum, Atari ST, classic Mac OS, OS/2 Warp, IBM 3270, Solaris CDE, RISC OS, GEOS, amber and green CRT, Teletext). Each Systems theme brings its own era typeface along for the ride.

The Interface Font setting changes the type across the whole suite independently of colour. New installs start on Poppins with the BrewBalance · Mocha colour scheme.

Game Install Folder

Control Panel → Library → Game Install Folder is where GOG and Epic downloads go. New installs use ~/Games/Clarity; Change Folder points everything somewhere else (a second drive, say) and Reset puts it back. Each game still gets its own sub-folder, and you can always override the folder for a single game while installing it.

Changing this only affects future installs — nothing already on disk moves. Games installed under a previous folder stay perfectly playable and can still be uninstalled normally.

Manage Storage

Control Panel → Library → Manage Storage answers “what is eating my disk?”. The GOG & Epic button opens Installer showing only installed games, sorted biggest-first, so the space hogs are at the top and one click uninstalls them. The Steam button hands you over to Steam’s own storage manager.

When a Download Stops Moving

A download can keep its connection open and its speed up while making no actual progress — usually because one of GOG’s content servers is handing out a damaged copy of a single file. On the surface that looks identical to a slow download, which is why it can go unnoticed for a long time.

Clarity watches the percentage itself. If it hasn’t moved for a few minutes, the Download Manager says so: the bar turns red and a note explains what is happening. It never cancels anything on your behalf — it cannot know whether a pause is fatal, and throwing away a part-finished download on a guess would be worse than telling you and letting you decide.

If you see it: cancel and start the download again. Nothing is lost — downloads resume from where they stopped — and the retry normally reaches a different server and carries on. Clarity also switches servers automatically when a file arrives damaged, so this should be rare.

DOS Games — which DOSBox runs them

GOG’s DOS games come with a Windows build of DOSBox from 2010, which on Linux has to run through Proton — an emulator inside a translation layer. It works, and it is what Clarity uses out of the box: you need install nothing.

A native DOSBox is better: faster, sound and fullscreen without Proton in the way, and still maintained. Clarity can use one, and crucially it reads the very same configuration file GOG wrote for that game — every tweak GOG made (CPU cycles, machine type, sound cards, the startup commands) is kept exactly. Only the emulator changes; nothing on disk is rewritten.

Control Panel → Tools → DOS Games:

  • Automatic (default) — use a native DOSBox if you have one, GOG’s if you don’t. Nothing to decide.
  • Native — always use the system one.
  • GOG’s — always use the bundled one, even when a native is available.

To get a native DOSBox, install dosbox-staging with your package manager — the card shows the exact command for your distribution, or flatpak install flathub io.github.dosbox-staging, which works anywhere. dosbox and dosbox-x are recognised too. Restart nothing; the card notices it immediately. If you install the Flatpak and a game refuses to start, its folder is probably outside the sandbox — give it access, or use the packaged build instead.

Which Screen Games Open On

On a multi-monitor machine games land on whichever screen the desktop calls primary, and most of them offer no way to change that. Control Panel → Which Screen Games Open On lists your monitors by name and size — a connector called DP-4 tells nobody anything — and every game opens on the one you pick. Default hands the decision back to the desktop.

This works on KDE and on Hyprland, and the card is hidden on any other desktop and on a single-monitor machine. On Hyprland it also sets the screen you picked as the primary output for X11 games — without one they take whichever monitor sits at the left edge of the desktop, which is how a game ends up running at a small screen’s resolution. On KDE it works by asking KWin to place the window, which is the only thing that can decide this under Wayland — nothing inside the game has a say. Nothing is written to your KDE settings, and the change applies to the next game you start, with no logout.

One caveat worth knowing: a game that runs fullscreen is re-fitted to the monitor you chose. Sending a game to a smaller screen means it plays at that screen’s size, which is a property of the monitor rather than something any setting can talk it out of.

Detect Genres

Control Panel → Tools → Detect Genres sorts your library by what each game actually is — ARPG, CRPG, FPS, Racing — rather than by the vague genre line stores hand out. See Genres for what it does and how to overrule it.

Scan for Updates — Your Games

Control Panel → Library → Scan for Updates checks the games you have installed for newer versions. Nothing is ever downloaded behind your back: the scan only ever hands you a list, and updating is one deliberate press per game.

  • GOG & Epic — a real check against the store. Each game shows installed version → latest version, and Update re-runs the normal install, which brings it up to date and shows up in the Download Manager like any other download.
  • Steam — flagged only. Clarity reads Steam’s own local files to see that an update is pending and hands you over with Open in Steam; it never pretends to update Steam games itself.

The GOG side is checked one game at a time (the store’s tooling doesn’t like being asked in parallel), so a big installed library takes a moment — there’s a progress bar, and “Everything is up to date” is a perfectly good result.

Your Version & App Updates

The Control Panel’s opening splash carries the version you are running, and next to it a Check for Updates button. It opens the releases page in your browser — that’s the whole mechanism.

Clarity has no auto-updater and no phone-home: nothing is checked in the background, and the app never contacts anyone to ask about itself. Compare the version on the splash with the newest release on the page; if it’s higher, read what changed and download the new AppImage yourself. Replacing the file is the entire update — your GameManagerConfig folder (library, artwork, settings, save backups) sits beside it and is untouched.

12. Couch — Overview & Setup

Couch is the suite’s living-room face: fullscreen, gamepad-first, TV-sized type. It reads the same library as the Manager — nothing to configure, nothing to copy.

Launch it from the Manager’s titlebar Couch button, the app menu entry (“Couch (Fullscreen)”), or Clarity.AppImage --couch. It can also autostart on login for HTPC builds (Control Panel → System).

First Run

A two-step setup asks how you want your start screen (Carousel or Grid of categories) and how you like to browse (List with a live media panel, or a cover Gallery). Both are changeable anytime in the menu. After that you land on the Home screen.

Waking up: while a game runs, Couch sleeps behind it. Press START + SELECT (configurable) to bring it back.

13. Couch — The Home Screen

A TV-style hub that greets you on boot (toggleable in the menu): library stats up top, Today’s Pick as a full-bleed banner (always a scraped game from your main stores), then rows you navigate with the d-pad — wrap around from bottom to top.

The Actions Row

  • Enter Library and Surprise Me (a roulette pick, straight to its gamepage).
  • Continue — your last-played game, one press away.
  • Jukebox — opens the music player; while a track plays, the tile becomes a live now-playing card with the song’s cover art, title, artist and a bouncing equalizer.

Rows & the TV Reader

Toggleable rows: Recently Imported, Hidden Gems, Recently Played, Most Played, Couch Night, Wishlist, Free This Week, Proton Watch, Gaming News and Your Games News. News articles open in the TV Reader — a clean, themed, big-type reading view with the article’s images. Scroll with the d-pad, page with L1/R1, open in a real browser with X if you insist, back with B.

Press Y anywhere on Home to jump straight into library search. Opening a game from Home and pressing B brings you back to Home — not the library.

14. Couch — Browsing the Library

Start Screen

Your categories — stores, filters and every playlist — as a horizontal carousel or a grid, each with a live art mosaic. A enters, Y searches within the highlighted category, B returns to Home.

Gallery Browsing

  • L1/R1 switch categories; d-pad navigates the grid; A opens the gamepage.
  • X opens Sort — the same six modes as the desktop (A—Z, Last Played, Favourites First, Want to Play First, Recently Added, Scraped First), remembered across sessions.
  • SELECT opens Playlists — jump to any playlist or create a new one with the on-screen keyboard.
  • Y searches; cards show install state, store badges and FREE pills.

Filtering by Genre

Genres are not another row of categories — they narrow whichever category you are already in. Open START → Library → Filter by Genre, pick one (every genre in your library, most-stocked first, with counts), and it applies on top: GOG becomes GOG CRPGs. The active genre shows as a coloured pill next to the category name, and All Genres clears it. The filter lasts for the session and is gone on the next launch, so it can never quietly hide half your library.

List Browsing

A vertical list with a live media panel: trailer or screenshots on the right, metadata below. X swaps trailer and screenshots; L1/R1 jump ten games; L2/R2 jump to the ends.

15. Couch — The Gamepages

Two styles, switchable live from the menu (Immersive is the default): Classic — hero art on top, scrolling page below with stats, achievements, description and screenshots. Immersive — your screenshots (or the trailer) fill the screen behind a tilted, glowing box art and glass info chips.

Both Pages Offer

  • Play / Install — installed games launch; GOG/Epic install in-process with folder and size confirmation; Steam games warn you that the desktop Steam client will open.
  • Favourite • Want to Play • + Playlist (toggle membership, create new) • Hide • Steam page • Uninstall • Trailer.
  • Y — the full achievements overlay (GOG and Steam, filters, per-store switching).
  • L1/R1 flip to the previous/next game without leaving the page.
  • The store/category logo in a corner, and a FREE pill on free-to-play games.

Immersive Extras

X opens the details modal: a large screenshot pane (flip with left/right) above the short summary and the complete Steam description. On the classic page the same content lives on the page itself, with the screenshot banner opening a fullscreen slideshow.

SELECT opens the game options menu on either page: trailers (download/delete), rename, mark played, playlists, the Scraping Engine (fix art and metadata from the couch) and Installer install/uninstall.

17. Couch — Jukebox & Atmosphere

Music

Three background modes (menu → Jukebox Mode): Ambient (built-in loops), Custom (your own music — drop MP3/OGG/FLAC/WAV files into the CUSTOM_MUSIC folder next to the AppImage), or Off. In Custom mode, L3/R3 restart or skip tracks from anywhere, and the Home screen’s Jukebox tile shows what’s playing.

The Jukebox

A full player: browse your tracks and music playlists, search, queue, see embedded cover art, go fullscreen for a now-playing view with a progress bar. Music playlists are separate from game playlists.

Screensaver & Sleep

After a configurable idle delay, the screensaver takes over — a slideshow of your own game screenshots, with a clock (turn it off in the menu if you prefer). While a game runs, Couch sleeps and shows the running game’s cover; wake it with START+SELECT.

18. Couch — Menus & Settings

Press START anywhere:

  • Audio — Jukebox mode, sound settings (volumes, SFX).
  • Appearance — Color Scheme (all 93 suite themes, in the same ten categories as the desktop; ★ Follow The Manager keeps Couch matched to your desktop theme automatically), Interface Font (the same six faces, each shown in itself so you can judge it at TV distance — and its own ★ Follow The Manager, which is how it starts out), Home Screen (startup toggle + row selection), Start Screen mode, Browse mode, Gamepage style (applies live, even inside a gamepage), Screensaver.

Renaming, scraping, downloading trailers, editing a launch command and uninstalling all live in the Manager, where a keyboard is.

19. Installer — the GOG & Epic Engine

Installer does the heavy lifting for DRM-free stores: authentication, downloads, Proton/Wine setup, redistributables, launching and uninstalling. Most of the time you never see it — the Manager and Couch drive it silently.

You no longer sign in here. GOG and Epic logins happen directly in the Manager’s Welcome and Connect screens. Installer’s window is for tuning, not setup.

It Has No Window

  • Per-game tuning — now in the Manager’s Compatibility panel: Proton version, Wine prefix, winetricks, environment variables, esync/fsync, DXVK-NVAPI, launch arguments, custom executables. You don’t have to set a Proton here — the suite finds one by itself (§7) — but this is where you pin a specific build for an awkward game.
  • “▶ Log” — Play with Log. Next to every installed game’s Launch button. It starts the game exactly as normal but streams everything the game and Wine print into a live window — the first thing to reach for when a title refuses to start. Copy the log with one button. Closing the window doesn’t disturb the game.
  • Manage Storage (Manager → Control Panel) — the old “⬇ Size” sort: — order the library by how much disk each install actually occupies. This is what Manage Storage opens.
  • DLC: list, install and reset the DLC of your installed GOG games.
  • Its download manager, install log and repair tools are reached from the Manager too.

GOG DLC is installed as a set. GOG’s downloader cannot safely add one DLC on its own — asking it to will delete the base game. So the DLC panel always reinstalls the game together with all the DLC you own, which is slower but never destroys anything.

Installer’s data lives in ~/.config/installer/ — logins and install records are per-machine, which is why a fresh copy of the suite still knows your GOG library on the same computer.

19b. Fan Games, Source Ports & Mods

Control Panel → Fan Games & Source Ports. A catalogue of things the suite knows how to install from a file you already downloaded — source ports, custom engines, standalone fan games, mods, and OpenBOR titles. Each entry says where to get the download and what the file is called, because that is the step that actually stops people.

You bring the port; the suite finds the game data. A source port without its game data is not a game, and you very likely already own the data in the library the suite is already managing. Install Ironwail and it links Quake’s pak files out of your GOG copy; install GZDoom and every Doom IWAD you own turns up beside it. Nothing is copied — the data stays in one place. If you own it but have not installed it, the entry says so by name; if the files never came from a store at all (arcade ROMs, a folder off an old disc), it asks you to point at them, and copies those, because a folder of yours may be moved or tidied away.

Games, not engines

Nobody sets out to install GZDoom — they set out to play Brutal Doom. So mods and Build-engine games are entries in their own right: choosing one installs the engine too if you have not got it, and appears in your library under the game’s own name. Blood, Duke Nukem 3D, Shadow Warrior, PowerSlave, Redneck Rampage and both Witchavens are separate entries, listed whether or not you own them, because the catalogue’s job is to say what is possible.

Choices happen when you press Play

  • Which Doom? — a mod runs on whichever Doom you feel like tonight, so the choice is made at launch, not baked in at install. It opens on whatever you picked last.
  • Which engine? — where two engines can both run a game, both are installed beside it and you pick as you start.

Anything not in the catalogue

A game folder you already have registers any folder holding a Windows game, where it sits — nothing copied or moved, so a folder on another drive stays there. It looks three levels deep, puts the likely entry point first and lets you name it. That is the right answer for anything self-contained: a fan game that ships its own engine, or a setup you assembled yourself. Any Quake mod or episode and Any Doom mod or texture pack do the same for mods, taking any archive and letting you choose what loads.

Games that ship their own patch DLL just work. Many older Windows games come with a community fix in a file like ddraw.dll or opengl32.dll. On Windows the game’s own copy wins; Wine normally overrides it, so the patch never runs and the game stops dead or starts untranslated. The suite spots those and hands the game its own, with Wine’s behind it as a fallback. Nothing to configure.

Some games are fixed by name. The rule above is a general one, and most compatibility problems are. A few are not — the fault belongs to one specific game and nothing else — and those are written down individually and applied when the game starts. OutRun 2006 is the clearest example: it opens to a white screen and looks frozen on the SEGA logo, when in fact its intro is a run of videos that can take over a minute to get through. The intro is skipped, so it does not happen. Others in the list: Resident Evil 2 with Classic REbirth, GOG’s Windows builds of Quake, Fallout: New California, Realms of Arkania, Albion and Colony Ship. Nothing to switch on, and the list grows.

20. Save Games — Backup & Restore

Installed GOG and Epic games get a Save Manager panel on their gamepage. GOG and Epic have no save-sync worth the name on Linux, so the suite gives you the honest version: find the saves, zip them up, put them back.

This is a desktop-face feature — it lives on the Manager’s gamepage, not in Couch.

Finding Your Saves

Save files hide in genuinely awful places — somewhere inside a Wine prefix, under a numeric account folder, or right next to the game. The Save Manager tries three things in order:

  1. The store’s own answer. GOG ships a save path inside each game’s manifest and Epic publishes a cloud-save folder; when either exists, that is used, account ID and all.
  2. The Wine prefix. Failing that, it searches the game’s prefix in the usual places (Documents, AppData, Saved Games), skipping the empty scaffolding Wine creates for every prefix.
  3. The install folder — where older games have always kept them.

If all three come up empty, use Locate saves… and point at the folder yourself; your choice is remembered. And “no saves yet” is a perfectly normal answer for a game you haven’t played.

Backing Up

Tick the folders you want and press Back Up. You get a dated ZIP with a manifest inside it recording where every file came from. Because the manifest travels with the archive, a backup made on one PC restores correctly on another, even with a different username, a different install path or a different account folder.

Restoring

  • Pick a backup and confirm — the panel tells you exactly what it’s about to overwrite.
  • A snapshot of the current saves is taken first, automatically, and filed alongside your other backups. If a restore turns out to be the wrong move, the state you just replaced is still sitting there.
  • Restore is a true replace, so a save the game deleted stays deleted — with a guard that refuses to wipe a folder shared by several games.
  • Delete any backup you no longer want from the same list.

Backups are ordinary ZIP files — copy them to a drive, a NAS or a cloud folder yourself. Nothing is uploaded anywhere on your behalf. LEARN MORE in the panel explains the whole flow in-app.

21b. On Omarchy

Clarity runs on any Linux desktop. It is built and tested on Omarchy, and there it does a handful of things it cannot do anywhere else.

Your Theme, Not Ours

The theme picker has a Your Desktop entry that reads the palette Omarchy is actually using — not a lookalike, the same colours. Change it with omarchy theme set and the app follows on its next start. The Control Panel’s Desktop page names the theme it found.

How a Game’s Window Opens

Control Panel → Desktop offers Fullscreen, Floating and Tiled. Fullscreen is the default and is what you want almost always: the game is handed the whole monitor the moment it opens, instead of being fitted into a tiling layout and resized a second before it goes fullscreen anyway.

Choose Floating if a particular game shows a small configuration window before it starts — every game launched through Proton arrives under the same window class, so a rule cannot tell the launcher from the game.

A window rule cannot be taken back. Hyprland keeps a rule for the rest of the session, so switching between these three normally shows up at your next login. The Apply To This Session button underneath makes it immediate by having Hyprland re-read its config and putting Clarity’s rules back — at the cost of window rules other tools set this session, which is why it is a button and not automatic.

Which Screen Games Open On

On top of the window rule, this sets your chosen screen as the primary output for X11 games. Hyprland’s XWayland starts with no primary at all, and a game that asks for one takes whichever monitor sits at the left edge of the desktop — if that is a small panel beside a large screen, the game sizes itself to the panel and stays there.

The Command Palette

Ctrl+K in the Manager opens a fuzzy list of every game and every settings page at once. Type a few letters, press Enter. Games open their page; actions run.

The Bar Widget and the Launcher

There is a separate Omarchy plugin for the bar: it shows how many games are installed and what is playing, with a menu one click from the library, Couch, Manage Storage and the Control Panel. It also adds a launcher overlay — bind it to a key, type a few letters of a game’s name and press Enter to play it, with its cover and a sentence about it beside the list.

The plugin reads ~/.config/clarity/desktop.json, which the app writes on every start, so it needs no configuration — and it needs the app to have been run at least once before it can show you anything.

The Gaming Stack

Omarchy ships as a developer desktop, so a fresh install has almost none of the gaming stack. Control Panel → Desktop lists what is missing — umu-launcher, Wine, DOSBox, GameMode, MangoHud, gamescope, 32-bit graphics drivers and the rest — and hands you the install command. It also reports two kernel settings a gaming distribution changes, without touching them: those belong to you and your distribution.

22. Tips & Troubleshooting

  • Steam import returns nothing: your Steam profile’s Game Details must be Public. Double-check the SteamID64 (17 digits).
  • A newly bought GOG/Epic game isn’t showing: hit Refresh Library — it pulls the fresh owned list from both stores. If it still doesn’t appear, open Connect and check the GOG/Epic cards still say you’re signed in; store tokens do expire, and signing in again takes a few seconds.
  • A Windows game won’t start: a game that quits the moment it starts now tells you so, with the technical details one click away. The usual cause is having no Proton installed, which the dialog offers to fix in one click — see §7. If you already have Proton, the same dialog lets you try a different build.
  • Nothing at all seems to happen on the first Windows game: it’s working. A compatibility runtime downloads once per machine and the game’s Windows environment is built the first time you play it — a few minutes, shown on the Now Playing card. Later launches are instant.
  • You want to see exactly what a game printed: open the game’s page in the Manager and use Play with Log from the Compatibility panel. The verbose output shows what Wine or the game actually complained about — usually a missing dependency you can install from the same panel.
  • A game vanished after Refresh Library: that’s the removal check — the store no longer reports you as owning it (refunded, or a demo you uninstalled). Re-buy or reinstall it and the next refresh brings it back.
  • A game shows Install instead of Play (or vice-versa): Refresh Library reconciles install state with Installer and Steam. Games owned on several stores at once count as installed if any copy is on disk.
  • Am I running the latest version? Open the Control Panel — the splash it lands on tells you your version, and Check for Updates next to it opens the releases page so you can compare. There is no automatic check; nothing is downloaded without you.
  • Missing artwork after import: run Batch Fetch; for stubborn games open Edit Details and scrape with a corrected title, or pick art manually via SteamGridDB.
  • GPU usage while idle: animations pause automatically when the window loses focus; the Ken Burns effect can also be disabled outright in Appearance.
  • Couch feels out of sync: it re-reads the shared database on focus and refresh — if you edited a lot on the desktop, back out to the Start screen and re-enter.
  • Moved the folder? Re-run Add to Application Menu so the launcher entries point to the new location.
