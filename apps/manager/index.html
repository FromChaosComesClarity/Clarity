CLARITY

GAMING SUITE

macOS build — Experimental

One app, many faces — your whole gaming world in one good plwed under one roof.

The Manager is the desktop hub: detail-obsessed, devoted to your library, doing all the heavy lifting — automatic and manual importing, artwork and metadata scraping. Installer works quietly under the hood, installing and launching your GOG and Epic games. Check the manual for everything else.

Couch is where you kick back: a fullscreen, controller-first companion, laidback and focused purely on fun — a true connoisseur of good games and good music. EmuLatte rounds out the suite for your emulators. Grab a controller and enjoy.

Which Screen Games Open On
On a multi-monitor desktop it is the compositor that decides where a game lands, not the game. This adds a single window rule so they open where you want, and on Hyprland it also makes that screen the primary one for X11 games — without a primary they pick whichever monitor sits at the left edge of the desktop, which on most desks is the small one. Both are the only settings that reach outside Clarity's own folder: they own that one rule, touch nothing else, and are undone by setting this back to Default and restarting the session.
Omarchy
Omarchy ships as a developer desktop, so a fresh install has almost none of the gaming stack. Here is what is missing, measured against the reference setup this app is developed on.
Steam is not installed. Most of a library lives there, and Omarchy's own installer also sets up the 32-bit graphics drivers picked for this machine — which Proton needs.
Installs run in their own terminal, so press Re-check when one finishes — no restart needed.
System tuning
Kernel settings a gaming-focused distribution changes and a general-purpose one leaves alone. Most of them are already right here — this only reports, and hands you the command for anything that is not.
Clarity can wear your actual Omarchy palette — not a lookalike, the same colours your desktop is using. Change it with omarchy theme set and this follows along. It is in the theme picker under Your Desktop too.

How a game's window opens
A Hyprland rule cannot be taken back once set, so a change only shows on the next login — unless you press this, which has Hyprland re-read your config and then puts Clarity's rules back. Anything else that set a window rule this session loses it.
Fan Games & Source Ports
Install source ports, custom engines and fan games from the file you downloaded. Clarity knows where each one comes from and what it needs — and wires up the game data from a title you already own, so a port never arrives unplayable.
DOS Games
GOG's DOS games come with a Windows DOSBox from 2010 that has to run through Proton. A native DOSBox reads the very same GOG configuration — every tweak GOG made for the game is kept, only the emulator changes.
Game Genres
Sort your library into real genres — ARPG, CRPG, FPS, Metroidvania, Racing — using the tags players voted on, so you can filter by what a game actually is. Anything you set by hand is never overwritten.

Back up this game's saves to a portable .zip you can keep or move to another PC, then restore them any time. Restoring always snapshots your current saves first. LEARN MORE ›

      

      

      

      

      

        
        
        
        
      

    

  


  

    

      

        
Save Manager — Guide

        
Everything you need to back up and restore your GOG saves on Linux — including how to find saves the app can't detect on its own.

      

      

        

        
Why this exists

        
Neither GOG Galaxy nor the Epic Games launcher runs on Linux, so your GOG and Epic save files normally have no backup at all. The Save Manager finds a game's saves, packs them into a portable .zip, and restores them whenever you need. It covers GOG and Epic — Steam has its own cloud saves, so it isn't included here.


        
How saves are located

        
When you open the Save Manager it shows one or more save folders, each with a small tag:

        
    
          
  • from GOG / from Epic — the store itself declared this location. The most reliable.
    • 
          
  • detected — found by scanning the game's Wine prefix (the usual save spots).
    • 
          
  • you chose this — a folder you picked yourself with Locate saves….
    • 
        

        
If it says “No saves found yet” and you have played the game, its saves live somewhere unusual — jump to “Can't find your saves?” below.


        
Backing up

        
    
          
  • Tick the folder(s) you want (some games split saves across two folders — all ticked ones go into one zip).
    • 
          
  • Press Back Up Now and choose where to save the .zip.
    • 
          
  • Keep that zip anywhere — an external drive, cloud storage, or copy it to another PC.
    • 
        


        
Restoring

        
    
          
  • Press Restore… to pick any backup zip, or press Restore next to one listed under “Previous backups”.
    • 
          
  • Before anything is overwritten, your current saves are packed into an automatic pre-restore snapshot — so a restore is always undoable.
    • 
          
  • Restoring on a different PC works too: the folders are re-homed to that machine's prefix automatically.
    • 
        


        
Managing backups

        
Each entry under “Previous backups” has a Delete button that removes only that .zip file. Your live saves are never touched by deleting a backup.


        
Can't find your saves? Locate them yourself

        
If detection comes up empty or points at the wrong folder, press Locate saves…. The folder picker opens inside the game's Windows environment, here:

        
~/.config/installer/prefixes/<Game>/drive_c/users/steamuser/

        
From there, saves are almost always in one of these — open them and look for the folder holding the actual save files:

        
    
          
  • Documents\My Games\<Game>
    • 
          
  • Saved Games\<Game or Studio>
    • 
          
  • AppData\Roaming\<Studio>, AppData\Local\<Studio>, or AppData\LocalLow\<Studio>
    • 
          
  • Some older games save inside the game's own install folder — look for a Save, SAVE or SAVEGAME subfolder there.
    • 
        

        
Select the folder that contains the save files and confirm. Your choice is remembered for that game; you can switch back later with “Use auto-detect instead.”


        
Native-Linux games

        
Some GOG games install as native Linux builds (Epic titles always run through Proton). A native build has no Windows prefix, so it can't be auto-detected — use Locate saves… and point at wherever the game stores them, commonly under ~/.local/share, ~/.config, or the game's install folder.


        
Your saves are safe

        
    
          
  • Backing up only reads your saves — it never changes them.
    • 
          
  • Restoring always snapshots the current saves first.
    • 
          
  • Nothing is ever deleted unless you press Delete on a backup.
    •
